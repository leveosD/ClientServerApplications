Здесь собраны мои лабораторные работы по дисциплине "Разработка клиент-серверных приложений".
Каждая из работ реализует подписку пользователей на определенные топики.

При отправке пользователь указывает топик, в котором он хочет отправить сообщение.
Его получат только те, кто подписан на сам топик или топик старшего разряда.
Пример:
User1 отправляет сообщение "hello!" в топик aaa.bbb.ccc
User2 получает сообщение, потому что подписан на топик aaa.bbb.ccc
User3 получает сообщение, потому что подписан на топик aaa.bbb
User4 не получит сообщение, потому что подписан только на топик bbb

Первая лабораторная работа реализует TCP соединение, вторая - UDP. Третья работает через REST API.
